# Samuria AI Generator (V1)

This is AI Generator project built using Python and OpenAI API.

## Features
- Generate text (social media posts) using AI
- Generate ads using AI
- Generate ideas using AI
- Simple command-line interface (CLI)
- User input for custom prompts

## Technologies Used
- Python
- OpenAI API

## Description
This project allows the user to enter a topic or idea , or ad or service, and the AI will generate a what ever he Enter and retrun response based on that input.
